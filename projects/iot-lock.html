Smart IoT Bicycle Lock

Year 2024
Category IoT & Telemetry
Duration 3 Months
Reliability 99.2% Transmission

Project Overview

The Smart IoT Bicycle Lock is a remote telemetry and device management system designed to provide GPS-based geofencing, motion-sensitive tamper detection, and real-time owner alerts over GSM/GPRS cellular networks. It transforms a standard bicycle lock into a connected security device.

The system represents a complete IoT vertical — from sensor interfacing and embedded firmware through cellular connectivity to a cloud-based monitoring dashboard.

Technical Details

  • GPS geofencing logic with configurable zone radius — triggers alerts when the bicycle leaves a user-defined boundary
  • ADXL345 triple-axis accelerometer for vibration-based tamper detection with programmable sensitivity thresholds
  • SIM800L GSM/GPRS modem integration — initially using raw AT commands, later migrated to TinyGSM abstraction layer for stability
  • MQTT protocol for lightweight bidirectional communication with cloud broker
  • Battery management system with solar trickle-charge capability for extended field deployment
  • OTA firmware update capability over GPRS for remote feature deployment without physical access

Challenges & Solutions

The initial implementation using raw AT commands for the SIM800L modem was plagued by intermittent connection drops and buffer overflows. Deep-diving into the serial communication logs revealed that the modem's unsolicited result codes were corrupting the AT command/response parsing. Replacing the manual AT command handler with the TinyGSM library resolved this entirely, achieving 99.2% transmission reliability.

Power management was another major challenge — the GPS and GSM modules are power-hungry. A duty-cycling scheme was implemented: GPS acquisition occurs only every 30 seconds during normal operation, increasing to continuous tracking when motion is detected.
